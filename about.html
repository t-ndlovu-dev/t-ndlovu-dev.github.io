About Me

I'm a web development student at the Catholic University of Zimbabwe, studying towards a BBMIT degree. I build clean, responsive, and accessible websites using semantic HTML5, modern CSS, and JavaScript.

This portfolio was built entirely from scratch — no frameworks, no templates. Every line of code was written and tested offline on an iPhone, version‑controlled with Git, and deployed on GitHub Pages. It demonstrates that I understand not just what to code, but why.

When I'm not coding, I'm learning about privacy‑first development, accessibility standards, and how to make the web work for everyone — regardless of device, connection, or ability.
